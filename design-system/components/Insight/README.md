# Insight

Recomendación de Oto: qué hacer, por qué y qué se espera, con la acción a un clic.

- Meta (plataforma · campaña) en `text-tertiary`; título = la acción concreta con números ("Subir el budget diario de US$ 200 a US$ 260").
- El porqué cita el dato que la justifica (CAC, CTR, frecuencia) contra una referencia.
- Impacto en deltas: clientes (bueno o malo) y gasto (neutro).
- Acción principal `--primary --sm` con el nombre de la plataforma; "Descartar" ghost. Toda acción que cambia una cuenta externa pide confirmación antes.
- Aplicada: se reemplazan los botones por un badge `--info` "Aplicado".
