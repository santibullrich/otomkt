# Card

Agrupa un bloque de información con su título; es el único contenedor con borde de la interfaz.

- `surface` + borde `border` + `radius-lg` + `shadow-card`; padding `space-5` (20px).
- Encabezado: `title-card` + subtítulo en `body-sm` que dice la conclusión o la fuente. La acción (botón ghost chico o segmented control) arriba a la derecha.
- No anidar tarjetas. Dentro de una tarjeta se separa con hairlines `border` o rellenos `surface-sunken`.
- Gap entre tarjetas `space-6` en desktop y `space-4` en móvil.
