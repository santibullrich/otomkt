# LineChart

Muestra cómo evoluciona una cantidad en el tiempo frente a un objetivo.

- Línea de 2px `series-1` con área al 12% y el último punto marcado (5px con anillo `surface`).
- Objetivo en punteada `chart-target`. La escala Y puede no empezar en cero; decirlo en el subtítulo si importa.
- Hasta 3 series en el orden fijo `series-1`, `series-2`, `series-3`; con dos o más, leyenda y etiqueta directa al final de cada línea.
- Hover con línea vertical, punto y tooltip (mes, valor, objetivo, diferencia).
- El subtítulo dice la conclusión ("650 en octubre, 25 sobre el objetivo"), no repite el título.
