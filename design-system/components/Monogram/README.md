# Monogram

Cuadrado con la inicial de una plataforma o un perfil que ayuda a reconocerlo en listas y tablas.

- Las plataformas conectadas toman su color de serie en el orden fijo (Google `series-1`, Meta `series-2`, TikTok `series-3`) y lo mantienen en tarjetas, tablas y gráficos.
- Las no conectadas usan `--neutral`.
- Es decorativo (`aria-hidden`): el nombre va siempre escrito al lado. No reemplaza los logos oficiales; si se suman, van en el mismo lugar y tamaño.
