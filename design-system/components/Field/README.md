# Field

Campo de formulario con su etiqueta visible arriba y una ayuda opcional abajo.

- Etiqueta siempre visible (13px, 500); el placeholder solo da un ejemplo, nunca reemplaza la etiqueta.
- Input de 40px, borde `border-strong`, `radius-md`. Foco: anillo `focus` de 2px con 2px de separación.
- Números editables con `.oto-input--num`: alineados a la derecha, cifras tabulares, la unidad en la etiqueta ("US$ K").
- Errores debajo del campo en `negative-text`, diciendo qué corregir.
