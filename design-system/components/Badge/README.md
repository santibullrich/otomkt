# Badge

Etiqueta corta de estado (factura, campaña, objetivo, contrato) que se lee de un vistazo en tablas y tarjetas.

- `--positive`: pagada, asignada, objetivo cumplido. `--warning`: por vencer, cerca del límite, revisar. `--negative`: vencida, excedida. `--info`: en aprobación, aplicada. Sin modificador: pausada, sin dato.
- Los estados con significado llevan ícono (tilde o signo de exclamación) además del color; nunca solo color.
- `--brand` (lima) solo para "Nuevo" o para destacar una función, una vez por pantalla.
- Una o tres palabras, sin punto final, en sentence case.
