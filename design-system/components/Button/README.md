# Button

Dispara una acción; el texto dice exactamente qué pasa ("Aplicar en Google Ads", "Generar contrato").

- `--primary` (relleno `brand`, texto `on-brand`): la acción principal de la vista. Uno por pantalla o por tarjeta de recomendación.
- `--secondary` (borde `border-strong`): acciones frecuentes que no son la principal (Exportar, Conectar).
- `--ghost`: acciones de baja prioridad o reversibles (Descartar, Cancelar).
- `--sm` (32px) en tablas y tarjetas densas; el tamaño base es 40px.
- Verbo + objeto, sin "Click acá". Mientras procesa: deshabilitado con gerundio ("Generando…").
